## MatchLens 0.4.9

- English is now the default interface language.
- Ukrainian is available in Settings → Language → Save.
- Profiles, source cards, charts, second-monitor view and Telegram follow the selected language.
- Previous-match roster filtering from 0.4.8 is included.

Download **MatchLens_0.4.9_Windows.zip**, extract the whole archive and run **Start.cmd**. Open Settings, install GSI once and restart CS2. Keep MatchLens running before your first match and between games.

Existing GSI and Telegram settings are retained when updating. Public data availability varies by source; Steam rosters are approximate and returning previous-match players need current-game GSI confirmation.
